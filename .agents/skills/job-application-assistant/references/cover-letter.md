# Rédiger une lettre de motivation adaptée

## Structure (3-4 paragraphes, une demi-page maximum)

1. **Accroche** : le poste précis visé, l'entreprise nommée, et une phrase
   qui montre qu'on a lu l'offre (une mission ou une valeur de
   l'entreprise mentionnée spécifiquement, pas une formule passe-partout).
2. **Pourquoi moi** : 1-2 réalisations concrètes du parcours de
   l'utilisateur qui répondent directement à ce que l'offre demande.
   Reprendre le lien fait à l'étape de tailoring du CV plutôt que
   répéter le CV mot pour mot.
3. **Pourquoi cette entreprise** : une phrase spécifique (produit,
   mission, actualité récente de l'entreprise) — jamais un paragraphe
   générique qui marcherait pour n'importe quel employeur.
4. **Clôture** : disponibilité, ouverture à un échange, formule de
   politesse adaptée au pays/secteur.

## Garde-fous

- Zéro placeholder oublié ("[Nom de l'entreprise]", "[Poste]") — relire
  avant de présenter le document à l'utilisateur.
- Ton adapté au secteur : plus direct/factuel en tech, plus formel dans le
  droit/la finance, plus incarné dans le milieu associatif ou créatif —
  demander le ton souhaité si le profil ne le précise pas.
- Ne jamais dupliquer une lettre déjà envoyée pour une autre offre en ne
  changeant que le nom de l'entreprise — au minimum le paragraphe 1 et 3
  doivent être écrits pour cette offre précise.
- Rester dans les faits présents sur le CV — mêmes règles anti-invention
  que pour le CV (voir cv-tailoring.md).
- Longueur : viser 200-300 mots. Un recruteur qui lit 200 lettres par jour
  ne lira pas une page entière.
