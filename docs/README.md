| Document | HTML | PDF |
|---|---|---|
| Registre des activités de traitement | [registre-traitements.html](./registre-traitements.html) | [registre-traitements.pdf](./registre-traitements.pdf) |

droit de rétractation, base légale par type de traitement) ont été ajoutés aux pages CGV et Politique de
confidentialité de la plateforme elle-même plutôt que dupliqués ici.
